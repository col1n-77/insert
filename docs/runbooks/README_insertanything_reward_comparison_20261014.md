# InsertAnything：现有原奖励策略与新增轴线奖励策略的比较

更新：2026-10-14。LHole-III，无触觉，初始夹爪竖直向下、插销绕 TCP Y 随机 ±10°，执行时开放六自由度。此次新增原版两权重的 1,024 回合评估，并复用已冻结的 Angle 两权重 1,024 回合，共比较 **2,048 回合、612,352 条逐步状态**。没有更改奖励、控制器或重新训练。

结论：现有最终权重的随机动作成功率基本持平，新增轴线奖励版本的平均末端轴线误差更小，但确定性成功率明显较低。现有训练配置不同，不能把差异全部归因于轴线奖励；没有证据证明当前新版本提高了插入成功率。

## 2. 完整回合评估结果

每个权重、每种动作模式均为 seeds 1001/2002 × 128 环境，即 256 个完整回合；每回合 299 个控制步，约 19.933 秒。确定性模式取策略高斯均值，随机模式从训练得到的动作分布采样；两者均沿用原动作限幅和 EMA 控制。

严格成功条件为原任务成功条件，另加物体/孔真实轴线夹角 <3°、深度误差 ≥−2 mm。所有原成功回合也通过严格条件，且回合结束时仍成功。各项角度统计包含成功及失败的全部回合。

| 权重 | 动作模式 | 严格成功 | 末端轴线夹角均值 | 夹角 P95 |
| --- | --- | --- | --- | --- |
| 原奖励最终 1,000 轮 | 确定性 | **200/256，78.13%** | 0.843° | 2.800° |
| 新增轴线奖励最终 100 轮 | 确定性 | **103/256，40.23%** | 2.423° | 8.487° |
| 原奖励最终 1,000 轮 | 随机 | **209/256，81.64%** | 1.212° | 3.123° |
| 新增轴线奖励最终 100 轮 | 随机 | **212/256，82.81%** | 0.745° | 3.109° |
| 原奖励最佳训练回报 846 轮 | 确定性 | 210/256，82.03% | 1.125° | 3.301° |
| 新增轴线奖励最佳训练回报 99 轮 | 确定性 | 106/256，41.41% | 2.266° | 8.174° |

最终权重随机模式仅多成功 3 回合，差 1.17 个百分点，95% Wilson 区间重叠；不足以宣称成功率提升。确定性下降 37.89 个百分点。最佳训练回报权重的补充结果也未显示新版成功率优势，不能用挑选一个 checkpoint 消除这一现象。

同一模式、种子的最终权重初始状态已做核对：确定性两组种子及随机 seed=2002 的初始物体位姿相同；随机 seed=1001 最大位置差仅 0.0087 mm、平均轴线夹角差约 0.000082°。因此初始条件基本匹配；这不消除训练配置的差异，也不把不同动作模式视为严格配对实验。两训练均只有一个训练 seed，不能据此声称跨训练种子的稳定优势。

原奖励的随机轨迹中，5.86% 的步数轴线夹角 >10°；新版为 0.70%。新版轨迹表现出更少的大角度偏离，但尚不能分离新增观测、奖励和训练设置各自的贡献。

## 3. 失败发生在哪里

| 最终权重、确定性模式 | 原奖励 | 新增轴线奖励 |
| --- | --- | --- |
| 失败回合数 | 56 | 153 |
| 失败中末端深度误差 >5 mm | 45 | **149** |
| 失败中末端轴线夹角已 <3° | 44 | **75** |
| 失败组末端深度误差中位数 | 11.42 mm | **25.03 mm** |
| 失败中最后 5 秒 TCP 运动范围 <1 mm | 13 | **75** |

这里深度误差为物体插入参考点高于目标点的距离，正值表示尚未到达目标深度；运动范围用最后 5 秒 TCP 三维包围盒对角线衡量。“已对准的 75 回合”与“停滞的 75 回合”是两个分别统计的集合，不能因计数相同就认为完全重合。

新版随机动作中最后 5 秒运动范围 <1 mm 的失败回合为 0，成功率明显高于确定性。这支持策略仍依赖随机动作完成搜索或脱离停滞的解释，但没有通过扫描动作噪声幅度的控制实验确认因果。两模型的最终高斯标准差范围相近（原约 0.67～0.77，新约 0.61～0.74，归一化动作单位），不能简单解释为新版探索幅度更大。

## 4. 奖励实现及逐项核验

用保存的物体/孔姿态、接触力、滤波动作和深度，重新计算原奖励及新增惩罚。612,352 条记录最大逐步重建绝对误差 **1.012e-6**；符号、角度单位、权重和逐步相加未发现错误。所有数组有限，成功判定复算一致；评估日志没有接触缓冲溢出、丢弃接触点、CUDA OOM 或异常栈。

原奖励已经包含 XY、深度、yaw、接近/半插入/成功阶段，以及动作和力惩罚。深度项受 XY 连续门控和 yaw <5° 门控影响；阶段项是满足条件后每步发放。接触力使用置零校准和 EMA 后的物体局部坐标系力，不是直接惩罚未经处理的夹持力。

新增奖励最终权重的**确定性失败回合，最后 5 秒**，平均每步加权贡献如下：

| 分量 | 平均贡献 |
| --- | --- |
| XY 奖励 | +0.6213 |
| yaw 奖励 | +0.5346 |
| 深度奖励 | +0.4537 |
| 接近阶段 | +0.2240 |
| 半插入阶段 | +0.0764 |
| 成功阶段 | 0 |
| 动作幅值惩罚 | −0.0370 |
| 动作变化惩罚 | −0.0036 |
| 力惩罚 | −0.0448 |
| 新增轴线惩罚 | −0.3899 |
| **总奖励** | **+1.4349** |

对准但未插入的区域仍有稳定正奖励，继续推进与保持当前状态之间的学习信号值得改善。这是候选学习停滞机制，**不能仅凭正奖励断定“原地停留是最优策略”**；插入成功还能获得更多奖励，优化步数、探索、优势估计同样可能影响结果。

力惩罚相对较小；上述失败片段只有 2.61% 的步数关闭 yaw 深度门控。二者目前都不是优先大改的证据。Gaussian 在大偏角时趋于饱和确实存在，但新版大偏角步数很少，且 75 个失败回合已经 <3°，因此单纯增大角度权重或放宽 sigma 不针对最突出的问题。

## 5. 建议的改进顺序（尚未实施）

### 先做同配置奖励对照

固定 27 维输入、零新增角度噪声、2,048 环境、minibatch=8,192、学习率、训练 seed 和预算，只改变 `align_weight=0/1`。两组均按同一轮数保存和评估，并同时报告环境转移数、实际更新数及两种动作模式。需要更稳健结论时，再增加训练种子。现在的 100 轮不能仅凭采样量超过原版就视为同等优化充分；也不能只依据 Adam 步数认定一定欠训练。

### 首个奖励候选：增加有效插入进度塑形

保留当前原奖励和轴线项，另外测试：

```text
r_new = r_original + r_axis + lambda * (gamma * Phi(s_next) - Phi(s))
gamma = 0.995
```

`Phi` 使用真实物体相对孔的有效插入进度；可以从平滑的 XY/yaw 接近程度，乘上截断到 [0,1] 的插入进度构造有界势函数。需要保持任务目标深度和成功条件一致，不能把 TCP 向下移动直接当作物体成功插入，也不能把物体在夹爪内的偏角归零当作目标。强度须独立短测，当前尚无验证后的 lambda。

该方向在原有绝对深度奖励之外提供状态变化的信号。采用势函数差分时必须正确处理真实终止和时间截断的 bootstrap，不能跨 reset 计算进度；否则不能援引保持最优策略的理论。简单只奖励 `max(向下进度, 0)` 容易鼓励反复上下移动，应避免。

形式依据：[Ng、Harada 与 Russell，1999，Policy invariance under reward transformations](https://people.eecs.berkeley.edu/~pabbeel/cs287-fa09/readings/NgHaradaRussell-shaping-ICML1999.pdf)。势函数塑形在相应条件下保持最优策略，不保证当前 PPO 训练一定更快或更稳定；这是待验证候选。

### 第二个候选：容许小误差，并按接近孔口的阶段调整轴线惩罚

在上述进度候选之外，单独测试小角度容差，例如容许 1° 以内误差，对超出的 `max(alpha-1°,0)` 继续用当前 Gaussian 惩罚；或测试随接近孔口平滑增强的权重。1°、阶段权重和缩放系数都是待验证候选，不是新默认值。评价轴仍为真实物体轴与孔轴，不是 TCP 是否竖直。

先分别对照，避免同时改权重、sigma、进度、力惩罚和 PPO 参数。当前不建议首先加重角度惩罚：较多失败已满足 <3°，再压小角度未必能让物体继续下插。仅把 `exp(...)-1` 改回 `exp(...)` 在当前固定时长下只是改变奖励零点，也不能解决这一问题。

推荐实验顺序为 A：同观测原奖励；B：当前原奖励＋轴线项；C：B＋进度塑形。使用共同的成功率、末端角度、插入深度、首次成功时间和停滞比例选型，不比较不同奖励定义下总回报的绝对高低。本次没有启动这些新训练。
