# Generated robot asset

`franka_gsmini_physx.usda` is generated on the first tactile environment launch
by `source/insertanything_tactile/assets.py::prepare_robot_asset()` from the
installed TacEx assets. The generated file contains absolute references to that
installation and is therefore excluded from Git. Install TacEx and its GelSight
Mini meshes and Taxim calibration before launching a tactile task.

To regenerate after moving or updating TacEx, remove only this generated layer
and launch the tactile task again. No meshes or TacEx calibration files are
redistributed in this repository.
